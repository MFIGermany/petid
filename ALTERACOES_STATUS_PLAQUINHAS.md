# Alterações — status das plaquinhas

- Dashboard: cada pet mostra, ao lado de Seguro/Perdido, se possui uma plaquinha ativa.
- Edição do pet: cada plaquinha vinculada mostra o estado Ativa ou Inativa.
- Somente a plaquinha com `status = 'active'` exibe o botão "Ver perfil público".
- Não houve alteração em rotas, banco de dados ou regras de autorização.
